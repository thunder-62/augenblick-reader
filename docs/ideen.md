# Ideen für später

Gesammelt während der Arbeit, bewusst **nicht** umgesetzt (CLAUDE.md: nichts bauen, was über den Auftrag hinausgeht).

- **Lesezustand an den Server melden** (ADR 004): für das Nutzungsprotokoll im Admin-Bereich (M2) und für mehrere Geräte pro Server (SPEC §12a).
- **Zweite Tagesausgabe am Nachmittag** statt einer festen Ausgabe pro Tag (ADR 003) – nur, wenn der Test mit der Nutzerin das nahelegt.
- **Admin-Status „letzter Abruf je Quelle“**: Die Daten liegen schon in der Tabelle `source_status` und in `/health`; in M2 im Admin-Bereich anzeigen.
- **Leiser Klick als Tipp-Feedback** (SPEC §8.1, optional) – erst nach Rückmeldung zum visuellen Feedback.
- **tagesschau in Einfacher Sprache** als eigene Rubrik oder als Stilvorbild für die Kurzfassungen (SPEC §5.1, [R30]) – Zugangsweg klären.
- **Branding-Ordner** `/branding/<name>/` (SPEC §12a): Name „Augenblick“ in der Übersicht kommt bereits aus der Locale; Logo und Akzentfarbe folgen, wenn ein Partner es braucht.
