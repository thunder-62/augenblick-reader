# Klick-Prototyp

Einzelne HTML-Datei zum Ausprobieren von Bedienung und Lesbarkeit auf Handy oder Tablet.
Lädt Nachrichten live auf dem Gerät von der öffentlichen tagesschau-Schnittstelle. Klappt das nicht, zeigt er frei erfundene Beispieltexte.

Dies ist ein Wegwerf-Prototyp und **nicht** Teil der Umsetzung nach `SPEC.md` (er nutzt z. B. Google Fonts und hat keinen Server).
